# Gsou VPS 出口管控

从主页打开 **VPS 出口管控**。它管理服务器出口，与本机的“分流”页面分别工作。
Windows 客户端通过 OpenSSH 调用 VPS 上的控制服务，与网站后台读取同一份生效规则。
只有节点列表中存在名称带 DMIT 标记的节点时才显示入口（不区分大小写）；
移除最后一个 DMIT 节点后入口隐藏，已打开的管控页面也会关闭。
打开时优先选择当前 DMIT 节点，否则使用列表中的第一个 DMIT 节点作为地址预填。

## 连接

填写 VPS 地址、SSH 端口、管理用户名（部署需要 root），选择本机的管理用 OpenSSH 私钥和已核对指纹的 `known_hosts` 文件，点击“保存连接并读取规则”。
只保存连接信息和文件路径，不读取、复制私钥内容，也不保存服务器密码。
现有只读监控账号和密钥不具备管理权限。
管理连接独立于当前代理节点，应用前请核对页面显示的服务器地址。

当前 DMIT 已部署控制服务，可以直接读取。需要新装或升级时，点击“部署 / 升级控制服务”。
安装使用客户端随附文件与 SHA-256 清单，不下载脚本；不会安装/重启 sing-box，也不会修改已有代理配置。
失败会恢复旧控制程序。控制服务使用私有 Unix socket，没有新增公网管理端口。

## 配置

- 分别选择 Claude、OpenAI、其他流量的出口；名称与 IP 从 VPS 读取。
- 自定义域名每行一个，包含子域名；不要填写网址、路径或端口。两个出口不能包含重叠域名。
- “检查规则”只校验；“保存并应用”确认后才提交到 VPS。
- “仅 Claude 走澳洲”先填入预设，保存应用后生效。
- “回滚上一版”恢复服务器的上一版规则，不使用本地尚未保存的草稿。

页面显示服务器实际配置、版本、任务状态和最近记录。
网页或另一个客户端已更新配置时，旧版本会被拒绝，先刷新后再修改。
提交后 SSH 短暂中断时只重试查询，不会重复提交写操作。
离开页面不会撤销服务器已经收到的任务，重新进入可继续核对结果。

## 当前部署包的适用范围

Linux、systemd、Python 3、curl，以及 `/root/sing-box/config.json` 和可执行核心。
VPS 须已配置 `direct`（直连）和 `au-residential-ai`（住宅 SOCKS5）两个出口，
并具备非 TLS VMess WS 入口供验证使用；服务发现不满足条件时会拒绝部署。
本功能不负责新增住宅代理账号、重装整台 VPS 或修改服务器入站节点。
出口地址会在部署预检时实测，包中没有绑定个人 VPS 的固定 IP 或代理凭据。

应用规则时会先在独立进程验证，再应用并复测真实入口、出口和 UDP；失败时自动回滚。
应用可能使 VPS 上的现有连接短暂重连，客户端 Windows Gsou 不会因此被重启。
